# بناء BCS Chart Studio كملف IPA عبر GitHub

هذه النسخة مجهزة لتتحول إلى تطبيق iPhone بدون الحاجة إلى Xcode على جهازك. GitHub Actions يبني تطبيق iOS غير موقّع، ثم تستطيع توقيعه وتثبيته باستخدام ESign بالطريقة التي تستخدمها عادة.

## ما الذي يحدث تقنيًا؟

- نسخة الكمبيوتر تبقى كما هي.
- أثناء بناء iOS يتم تجهيز نسخة Web محلية داخل مجلد `www`.
- Capacitor 8 ينشئ حاوية iOS أصلية باستخدام WKWebView وSwift Package Manager.
- ملفات BCS نفسها تكون داخل التطبيق؛ لذلك لا يحتاج iPhone إلى `localhost:8787` أو إلى تشغيل الكمبيوتر.
- التطبيق يتصل مباشرةً بخدمات Binance عبر HTTPS وWebSocket.
- GitHub يخرج ملف IPA غير موقّع جاهزًا للتوقيع الخارجي.

## الطريقة الأسرع

1. أنشئ Repository جديدًا على GitHub.
2. ارفع **كل محتويات المشروع** إلى جذر الـRepository، بما فيها مجلد `.github` المخفي.
3. افتح تبويب **Actions**.
4. اختر Workflow باسم **Build iOS IPA**.
5. اضغط **Run workflow** ثم **Run workflow** مرة أخرى.
6. انتظر حتى تصبح العلامة خضراء.
7. افتح الـRun المكتمل، وفي قسم **Artifacts** حمّل:
   `BCS-Chart-Studio-v...-unsigned-IPA`
8. GitHub ينزّل Artifact كملف ZIP؛ فك الضغط مرة واحدة وستجد داخله ملفًا مثل:
   `BCS-Chart-Studio-v1.5.0-unsigned.ipa`
9. انقل الـIPA إلى iPhone أو افتحه فيه.
10. داخل ESign: Import ثم Sign ثم Install باستخدام الشهادة التي تستعملها أنت.

## Public أم Private؟

إذا كان الـRepository عامًا، فـGitHub يوفر Standard GitHub-hosted runners مجانًا وبدون حد استخدام للمستودعات العامة. إذا كان Private فسيستخدم رصيد GitHub Actions المضمّن في حسابك. إذا كان شرطك عدم الدفع نهائيًا، اترك Spending limit عند $0 ولا تضف وسيلة دفع خاصة بـActions.

## متى يعاد بناء IPA؟

الـWorkflow يعمل بطريقتين:

- يدويًا من Actions > Build iOS IPA > Run workflow.
- تلقائيًا إذا أنشأت Tag يبدأ بـ `v` مثل `v1.5.0`.

## ماذا أفعل بعد كل تحديث للمنصة؟

ارفع الملفات الجديدة إلى GitHub ثم شغّل نفس Workflow. لا تحتاج إنشاء مشروع iOS جديد يدويًا؛ GitHub يعيده من المصدر كل مرة.

## هل يحتاج الكمبيوتر بعد تثبيت التطبيق؟

لا. التطبيق يحمل ملفات BCS داخله ويتصل بـBinance مباشرة. يحتاج الإنترنت فقط لجلب السوق الحي والتاريخ من Binance.

## التخزين

Watchlist والرسومات والـWorkspaces والسكربتات تُحفظ في مساحة التخزين الخاصة بالتطبيق على iPhone. حذف التطبيق من iOS قد يحذف هذه البيانات، لذلك استخدم Export Workspace دوريًا قبل حذف التطبيق أو تغيير التوقيع إذا كانت طريقة توقيعك تؤدي إلى تثبيت التطبيق كحزمة جديدة.

## إذا لم تظهر بيانات Binance

- تأكد أن iPhone متصل بالإنترنت.
- جرّب Spot وFutures كلًا على حدة.
- بعض الشبكات/VPN/DNS قد تمنع نطاقات Binance أو WebSocket.
- التطبيق لا يعتمد على `localhost`، لذلك لا حاجة أن يكون الكمبيوتر على نفس Wi‑Fi.

## ملاحظة التوقيع

GitHub يبني الـIPA فقط ولا يضع شهادة Apple أو provisioning profile داخل المشروع. التوقيع والتثبيت النهائيان يتمان عندك باستخدام ESign وشهادتك، وبالتالي لا نخزن أي شهادة أو مفتاح خاص داخل GitHub.
