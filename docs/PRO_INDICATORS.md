# BCS Pro Indicators

## مبدأ الحزمة

BCS Pro لا ينسخ مؤشرات مدفوعة مغلقة المصدر. الهدف هو بناء أدواتنا الخاصة استنادًا إلى مفاهيم تحليل فني معروفة ووظائف يعلن عنها الناشرون علنًا، ثم تنفيذ الخوارزميات من الصفر بما يناسب محرك Binance Chart Studio.

## حزمة v1.4

| المؤشر | الفكرة | أفضل استخدام مبدئي |
|---|---|---|
| Harmonic PRZ Scanner | XABCD + PRZ | انعكاسات محتملة بعد اكتمال النمط |
| Pattern Breakout Radar | converging regression channel | اختراقات بعد الضغط |
| Institutional Imbalance Pressure | unresolved FVG pressure + volume decay | قراءة ضغط عدم التوازن |
| Order Block Mitigation Map | BOS-derived blocks + mitigation | مناطق إعادة الاختبار |
| Compression / Expansion Regime | BB width + ATR + ADX | تمييز الضغط والتوسع |
| Momentum Structure Bias | momentum-derived S/R | bias واتجاه البنية |
| Projected ATR Volatility Levels | anchored ATR projections | أهداف/حدود حركة محتملة |
| Demand / Supply Zone Engine | base + impulse zones | مناطق العرض والطلب |
| Weighted Curve Channel | weighted moving-average curve | اتجاه وقنوات ديناميكية |
| Rolling Volume Profile Map | rolling POC / VAH / VAL | مناطق قبول الحجم |

## ملاحظة

هذه الأدوات تحليلية وليست توصيات تداول. القيم الافتراضية نقطة بداية ويمكن تعديلها من إعدادات المؤشر حسب الفريم والسوق.
